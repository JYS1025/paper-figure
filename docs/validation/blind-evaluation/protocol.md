## 익명화와 보존

- 공개 논문의 원본 PNG와 최신 생성본의 저장된 PPTX에서 렌더링한 PNG를 사용했다. 원본 파일은 수정하지 않았다.
- 이미지 위에 별도의 PDF 사각형을 놓아 내부 텍스트·숫자 라벨을 가렸다. 연산 기호 +, 반복 생략점, 연결선과 그림 요소는 유지했다. 재생성·인페인팅·도형 재작성은 하지 않았다.
- 생성본의 외부 제목과 설명용 푸터, CLIP의 외부 패널 제목은 표시 영역 밖으로 제외했다. 원본 비율을 보존한 채 같은 크기의 좌우 영역 안에 맞췄다. 같은 정보량·같은 도형 크기를 강제로 만들지는 않았다.
- 균형 배치(A 정답 2개, B 정답 2개)의 순서와 쌍 순서를 무작위로 정했다. 시드·위치·원본 해시·마스크 좌표·제시 이미지 해시는 별도 `answer-key.json`에 기록했다. 생성 코드와 정답표는 검증자에게 제공하지 않았다.
- 전달용 PDF도 마스킹이 끝난 PNG 네 장만 포함한다. 원본 이미지나 가려진 글자를 PDF에서 추출할 수 없도록 평탄화했다. PDF는 4쪽, 쪽당 이미지 1개, 추출되는 텍스트 0개임을 확인했다.

## 검증 실행

현재 모델을 **이전 대화를 상속하지 않는 별도 컨텍스트의 검증 에이전트**로 1회 실행했다. 모델 종류를 별도로 바꾼 타 서비스 교차 검증은 아니다. 작업 이름은 `/root/blind_visual_verifier`이다.

허용 입력은 `evaluator-prompt.md`와 `pair_01.png`부터 `pair_04.png`까지 정확히 다섯 파일이다. 폴더 탐색, 다른 파일, 메타데이터, 원본, 인터넷 조회를 금지했다. 판별과 피드백을 확정할 때까지 정답을 전달하지 않았다. 네 이미지를 본 뒤 남긴 응답은 원문으로 보존한다.

## 한계

- 유명한 논문의 도형 구도 자체가 기억 단서다. 따라서 출처·텍스트를 숨긴 것이 논문에 대한 사전 지식까지 통제한 것은 아니다. 기억에 의한 인식 여부를 별도로 물었다.
- 서로 관련된 유형의 figure지만 동일한 방법·내용의 두 시각화는 아니다. 복잡도·패널 수·종횡비 차이가 있다. 특히 Transformer 전체와 한 반복 블록 예제는 정보량이 다르다.
- 마스크는 글자의 의미와 타이포그래피를 숨기며, 마스크의 분포가 간접 단서가 될 수 있다. 이를 판단 근거로 삼지 말라고 요청했지만 영향을 완전히 제거할 수는 없다.
- 4쌍, 검증자 1회의 질적 진단이다. ‘출처 판별 정답률’을 논문 수준 달성도·AI 탐지 성능·일반화된 품질 점수로 해석하지 않는다. 제시된 확신도는 보정되지 않은 자기 평가다.
- 도형이 시각적으로 불완전해 보인다는 관찰과 방법이 과학적으로 잘못되었다는 판단은 구분한다. 라벨을 가린 상태에서 의미 정확성은 평가하지 않았다.

원본 URL과 파일 해시는 정답표에 기록했고, 최종 보고서에서 사람에게 공개한다. 검증용 ZIP에는 정답·출처·검증 결과가 포함되지 않는다.
