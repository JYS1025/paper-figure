# 논문 figure 색감 조사

2026-09-30. 모델 구조도와 방법론 도식 7편을 시각적으로 검토하고, Nature와 Color Universal Design의 원문 지침을 대조했다. 기존 figure와 스킬은 변경하지 않았다.

## 범위와 결론

이 표본에서 반복된 구성은 **흰 바탕, 어두운 글자, 넓은 면의 밝은 색, 의미가 있는 작은 요소의 선명한 색**이다. 청색·청록·보라·살구색·연녹색이 여러 사례에 나타나지만, 논문 전체의 색상 사용 빈도를 측정한 결과는 아니다. “논문용이면 무조건 저채도”, “색은 반드시 세 가지 이하”라는 결론은 지지하지 않는다.

파스텔을 사용해도 경계·글자·강조가 명확하면 읽기 쉽다. 반대로 모든 면, 선, 글자를 비슷한 명도와 채도로 만들면 정보의 중요도가 평평해진다. 색 이름을 바꾸기 전에 어느 대상에 얼마나 강한 색을 줄지 정하는 것이 더 중요하다는 해석이다.

## 원본별 관찰

| 논문과 원본 | 관찰한 색감 | 역할과 배분 |
|---|---|---|
| [Transformer, Fig. 1](https://arxiv.org/html/1706.03762v7/Figures/ModalNet-21.png) | 연살구·하늘색·분홍·옅은 노랑·연보라·연녹색 | 연산별 면색은 밝지만 테두리·화살표·글자는 검정이다. 여러 색이 있어도 같은 연산에 같은 색을 반복한다. |
| [CLIP, Fig. 1](https://arxiv.org/html/2103.00020v1/main-diagrams.png) | 연보라·연녹색·연파랑 | 텍스트·이미지·대응 행렬을 구분한다. 면보다 진한 같은 계열의 테두리를 사용하며, 역할이 여러 패널에 유지된다. |
| [MAE, Fig. 1](https://arxiv.org/html/2111.06377v3/arch.png) | 청록·산호색·회색·회갈색 | encoder/decoder는 회색이다. 토큰 표현과 마스킹 관련 구분에 색을 집중한다. 사진 색과 도식용 색은 별개다. |
| [U-Net, Fig. 1](https://lmbweb.informatik.uni-freiburg.de/people/ronneber/u-net/u-net-architecture.png) | 파란 특징 지도, 남색·적갈색·초록·청록 화살표 | 특징 지도는 하나의 색 계열로 통일하고 연산 종류를 화살표 색으로 구분한다. 원색에 가까운 색도 사용한다. 이 옛 사례를 현재의 접근성 모범으로 간주하지는 않는다. |
| [SAM, Fig. 4](https://arxiv.org/html/2304.02643v1/model_diagram.png) | 연녹색 image encoder, 연보라 prompt encoder, 연살구 mask decoder, 회색 임베딩 | 세 종류의 연산과 중간 표현을 구분한다. 사진과 분할 결과의 색을 도식 전체에 무작위로 확장하지 않는다. |
| [AlphaFold, Fig. 1e](https://www.nature.com/articles/s41586-021-03819-2) | 큰 모듈은 옅은 회색, 표현은 주황·연파랑, 흐름은 청색 계열 | 큰 연산 상자는 뒤로 물리고 MSA·pair representation의 구별을 남긴다. 같은 figure의 단백질 비교 패널에는 훨씬 선명한 청색·녹색도 등장한다. 패널의 역할에 따라 강도가 다르다. |
| [spinDrop, Fig. 1](https://www.nature.com/articles/s41467-023-40322-w/figures/1) | 장치·workflow의 회색, 유체의 옅은 청색, 전극의 붉은색, 광학계의 녹색 | 무채색 장치와 흑백 현미경 사진이 큰 면적을 차지하고, 재료·부품의 의미를 색으로 구분한다. 같은 분야의 현재 테스트 그림에 가장 직접적인 비교 대상이다. |

원본 네 편의 평평한 색 영역에서 추출한 RGB 표본과 현재 도식에 대한 제안은 [색상 비교 이미지](../output/color-study/paper-figure-palettes.png)에 있다. HEX는 저장된 원본 PNG의 픽셀값이며 저자가 지정한 원본 팔레트 값이라고 보장하지 않는다. 사진 색·안티앨리어싱을 포함한 전체 색 빈도나 면적비를 의미하지 않는다. AlphaFold, SAM, spinDrop은 브라우저에서 시각 검토했으며 정확한 RGB를 추출하지 않았다. NOVAsort는 이미지가 부분적으로만 로딩되어 완전한 figure 분석에서 제외했다.

## 실제 사용 사례와 권장 지침의 구분

- [Nature figure guide](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)는 접근 가능한 팔레트를 요구하고, 색이 들어간 글자보다 검은 글자와 색상 키·지시선을 권장한다. 과거에 출판된 그림이 현재 지침을 모두 충족하는 것은 아니다.
- [Color Universal Design의 배색 설명](https://jfly.uni-koeln.de/colorset/)은 작은 표시를 위한 강조색과 넓은 영역을 위한 밝은 바탕색을 구분한다. 큰 면의 파스텔과 작은 기호의 선명한 색은 함께 쓸 수 있다.
- [Okabe·Ito의 원문 지침](https://jfly.uni-koeln.de/color/)은 작은 물체와 얇은 선에서 색을 식별하기 더 어렵다는 점과, 색 외에 모양·위치·선 종류도 병용해야 함을 설명한다. 파스텔 몇 개를 골랐다고 색각 접근성이 확보되는 것은 아니다.
- [Wong의 Color coding](https://www.nature.com/articles/nmeth0810-573)은 범주 구분과 수치의 연속적 변화에 같은 색 전략을 적용하는 문제를 설명한다. 연속량의 heatmap과 모듈 종류를 나누는 도식 팔레트는 따로 정해야 한다.
- [Nature의 최종 제출 지침](https://www.nature.com/nature/for-authors/final-submission)은 RGB 제출을 권장하며, 인쇄용 CMYK 변환에서 밝은 색이 흐려지거나 색 간 대비가 줄 수 있음을 명시한다. 모든 저널에 같은 제출 규정을 일반화하지 않는다.

## 현재 미세유체 figure에 대한 제안

현재의 청회색·보라·녹색 조합은 연구 도식의 범위를 벗어나지 않는다. 아래는 시각적 위계를 더 분명하게 만드는 후보이며 아직 재색칠하거나 검증하지 않았다.

| 역할 | 제안 | 적용 방식 |
|---|---|---|
| 글자 | 중립적인 짙은 회색 `#242424` | 장치·전극·출구 라벨을 같은 글자색으로 유지한다. 의미 구분은 인접 도형과 기호가 담당한다. |
| 칩·채널 | 밝은 회색 `#EEF0F2` | 넓은 면을 얌전하게 두되 경계는 별도의 충분히 진한 회색으로 남긴다. |
| 유체·일반 액적 | 청색 `#0072B2` | 작은 윤곽과 표시의 기준색. 액적 내부나 넓은 유체 영역에는 더 밝은 tint를 쓴다. |
| 제어 신호·전극 | 보라 `#8064A2` | 점선·전극처럼 작은 면적에 사용한다. 큰 detector/controller 상자는 매우 연한 면색을 유지한다. |
| 양성 액적 | 청록계 녹색 `#009E73` | 중앙의 채워진 점과 양성 표시를 강조한다. 음성의 빈 원, 임계값 라벨을 함께 유지한다. |

이 조합의 HEX는 이번 작업을 위한 제안이지 특정 저널의 공식 팔레트가 아니다. 조합 전체에 대한 색각 시뮬레이션과 실제 크기 검토는 적용 시 별도로 해야 한다. 모든 글자를 보라·초록으로 칠하기보다는 도형과 신호의 색에 역할을 맡기는 방향을 우선 제안한다.

스킬에 반영한다면 하나의 고정 팔레트를 강제하기보다 **역할→색 매핑, 넓은 면/작은 표시의 강도 차이, 중립적인 글자, 분야별 참고 그림, 색각·흑백·출판 크기 검토**를 선택 절차로 만드는 것이 적절하다. 이 문서는 조사·분석 보고이며 해당 변경은 아직 수행하지 않았다.
