# 연결선의 시각적 무게 조정

2026-09-29. 얇은 화살표가 기계적인 인상을 강화한다는 사용자 피드백에 따른 수정이다. [이전/수정 비교](../output/gallery-arrows.html), [PPT 묶음](../output/paper-figure-arrow-examples.zip).

기존 8개 PPTX를 다시 읽고 연결선 스타일만 국소 수정했다. 기존 주 흐름은 주로 1.3px(0.975pt), 일부는 1.1px였고 화살촉은 모두 가장 작은 크기로 고정되어 있었다. 도형 테두리와 흐름의 굵기 차이가 작아 핵심 경로가 잘 드러나지 않는다고 판단했다.

폭 177.8mm에서 주 흐름을 2.6px(1.95pt), 스킵/조건/지도 입력을 1.7px(1.275pt), 학습 갱신을 1.9px(1.425pt)로 조정했다. 합류 후 최종 출력 경로 한 곳은 3px(2.25pt)다. 중간 크기의 삼각 화살촉과 둥근 선 끝/연결부를 사용했다. 색상, 점선 여부, 방향, 연결 대상과 배치는 그대로다. 03 상단의 상태 열에 쓰인 작은 수동 선/삼각형은 보조 개요이므로 유지했다. 이 값은 이 예제의 디자인 선택이며 출판 규격이 아니다.

두께 조정으로 의미적 세부 정보나 구도 자체가 좋아졌다고 주장하지 않는다. 이번 비교는 같은 그림에서 연결선 처리의 효과를 볼 수 있도록 구성했다. 남아 있는 약한 대각선, 넓은 빈 공간, 실제 논문 데이터가 아닌 설명용 표현은 선 굵기만으로 해결되지 않는다.

## 보존과 확인

- 각 원본의 현재 SHA-256과 객체 fingerprint를 확인한 후 수정했다. 원본 PPTX는 덮어쓰지 않았다.
- 비대상 객체의 fingerprint, 모든 연결선의 geometry/endpoint ID/방향이 동일하다. 사진·텍스트·도형 위치를 재생성하지 않았다.
- 슬라이드 XML 외의 ZIP 파트 내용이 byte-identical이다. [실행 기록](validation/arrows/summary.json)과 파일별 plan/patch/inspect 기록을 보존했다.
- 8개 내용 계약과 최종 패키지/크기/폰트/재import 검사를 통과했다. 전달 파일은 검토한 파일과 SHA-256이 동일하다.
- 저장된 파일을 번들 LibreOffice → PDF → Poppler로 렌더링해 8개 모두 게재 폭에서 검토했다. 앱 수동 편집 검사를 새로 수행한 것은 아니다.
- [21개 기능 검사](validation/arrows/tests.txt)가 통과했다. 이번에 연결선 스타일 변경의 비대상 보존과 잘못된 대상/굵기 거절을 추가했다.

스킬에는 선/화살촉/경로 역할을 함께 설계하고 최종 게재 폭에서 비교하는 지침을 추가했다. 도구의 화살촉 크기 고정을 제거해 이후 생성에서도 설정을 유지한다. `style_connector` 부분 수정은 연결선의 경로나 배치 문제를 자동 해결하는 기능이 아니다.
