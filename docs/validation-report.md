- 실제 편집 앱: macOS Microsoft PowerPoint 16.113.2. 별도 시험 복사본만 UI에서 편집했다.

## 실제 PowerPoint 동작

`output/powerpoint-source-snapshot.pptx`는 UI에서 수정하고 저장한 파일의 고정 복사본이다.

| 조작 | 관찰된 결과 | 증거 범위 |
|---|---|---|
| Encoder 글자 수정 | `Encoder edited`로 변경 후 저장·재열기 유지 | 실제 앱 UI + 저장된 XML |
| 모듈 이동 | encoder 위치가 (261,100) → (262.4769,103.9298)px로 변경 | 실제 앱 조작 및 위치 값 |
| 연결선 유지 | 두 선의 높이가 0 → 3.9298px로 바뀌며 모듈 양쪽에 붙음 | 실제 화면 + stCxn/endCxn + 저장 좌표 |
| 그룹 셀 접근 | 네 셀을 개별 shape로 인식; 한 셀의 위치 수정 후 그룹 구조 유지 | 실제 앱 UI |
| 그룹 전체 이동 | 화면에서 드래그 후 그룹 x가 37.4769 → 63.0769px로 이동 | 실제 앱 드래그 + 저장 좌표 |
| 수식 표시 | `hₜ₊₁ = hₜ + fθ(hₜ)`가 네이티브 텍스트로 보임 | 실제 화면·텍스트. OMML 검증 아님 |
| 저장·재열기 | 수정된 글자와 연결된 도형 및 그룹이 다시 열림 | 실제 앱 UI |

예제 8개 각각에서 모든 조작을 반복한 결과는 아니다. 복잡한 우회 경로의 이동 후 자동 재배치, 연결된 그룹 전체 이동, 고급 수식, 한글 폰트는 미검증 범위다.

## 최신 사용자 변경 보존

PowerPoint로 수정한 파일을 최신 입력으로 읽어 `Output y`만 `Result y`로 바꿨다. 결과는 `output/powerpoint-preserved.pptx`다. Encoder의 직접 편집·이동, 셀/그룹 위치 변경을 유지했다. 변경되지 않은 20개 ZIP 파트의 내용은 byte-identical이며, 같은 슬라이드의 비대상 객체도 fingerprint가 동일하다. [수정 계획](preservation-plan.json), [실행 영수증](preservation-receipt.json), [객체 비교](validation/preservation.json)를 보존했다. 원본 재생성 코드는 실행하지 않았다.

부분 수정 결과를 PowerPoint 16.113.2에서 실제로 열어 `Encoder edited`와 `Result y`가 함께 나타나는 것, 이동된 모듈에 붙은 두 연결선과 이동된 토큰 그룹을 화면에서 확인했다.

부분 수정 파일도 패키지·화면 크기·폰트 사용·재import 검사를 통과했다. [최종 검증 기록](validation/preserved.validation.json)의 SHA-256은 전달 파일과 일치한다.

## 기능 검사

[15개 검사 결과](validation/tests.txt): 필수 연결 누락, 화살표 역전, dangling 참조, 중복 ID, 잘못된 라벨을 실제 실패로 검출했다. 정상 예제 검사, 텍스트 국소 수정, 비대상 객체/파트 보존, stale source/target 거절, 원본 덮어쓰기 거절, 직선 연결된 도형 이동, 그룹 이동, 미지원 우회선 이동 거절, 실제 PowerPoint 편집 보존을 확인했다. 스킬 공식 `quick_validate.py`도 통과했다. 번들 Python에 PyYAML이 없어 이미 설치된 Anaconda Python으로 해당 검증만 실행했으며 새 패키지는 설치하지 않았다.

## 시각 검토의 한계와 수정 이력

첫 export에서 첫 객체 ID 참조 오류와 화살표 끝점 해석 문제를 발견해 호환성 단계를 추가했다. 첫 시각 검토에서 04의 숫자/선 겹침을 수정했다. 03/08의 같은 면을 잇는 우회선은 렌더러별로 경로가 달랐고 추가 조정값도 신뢰할 수 없었다. 최종 버전은 배치를 바꿔 일반 elbow 경로로 읽히게 했다. 실험용 경로 강제 지정 코드는 공개 제작 도구에서 제거했다.

최종본은 확대 렌더링과 672px 출판폭 미리보기에서 검토했다. 이것은 실제 출력물의 육안 인쇄 검사가 아니다. 한 단 폭인 약89mm로 절반 축소해도 읽힌다는 주장을 하지 않는다. 최소 글자는 08의 update 라벨 8.25pt, 나머지 보조 텍스트는 주로9pt다. 필요한 학회 규정에 따라 재설계해야 한다.

## 비교 평가 상태

A 일반 PPT, B 참고 추가, C 제작 도구 추가, D 렌더링 검토 추가의 32개 독립 모델 실행은 **미실행**이다. [결과 행렬](validation/model-comparison.json)에 `not_run`과 null 점수를 명시했다. 동일 모델/입력/전체 예산, 독립 문맥, 순서 무작위화, 블라인드 시각 평가의 [프로토콜](../skills/paper-figure/references/evaluation.md)은 준비했다. 이번 예제와 자기 시각 검토를 그 비교 실험으로 포장하지 않는다. 인간 수동 수정 시간도 측정하지 않았으므로 개선 비율을 보고하지 않는다.
