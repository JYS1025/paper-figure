# 사용자 제공 시각 평가 반영

2026-09-30. [사용자가 붙여준 평가 원문](validation/feedback-revision/user-feedback.txt)을 바탕으로 네 예제를 수정했다. PAIR 01은 개요도로 성립하고, PAIR 02는 원본과 완성도가 비슷하다는 평가를 유지한 채 지목된 연결·대응 관계를 보완했다. 모든 생성본을 논문에 쓰기 어려운 그림으로 단정하거나, 출처 판별 정답률을 품질 점수로 환산하지 않았다.

[수정 전후 비교](../output/gallery-feedback.html) · [수정 PPT 4개](../output/paper-figure-feedback-examples.zip)

## 반영한 내용

| 평가 쌍 / 파일 | 반영 | 의미를 임의로 추가하지 않은 부분 |
|---|---|---|
| PAIR 01 / 04-skip | 연결 대상을 라벨 영역에서 실제 특징 평면으로 변경. 병목 입출력과 두 decoder 입력을 도형 경계에 연결. H×W → H/2×W/2 → H/4×W/4의 면 크기도 정확히 80→40→20으로 구성 | 원래 과제에 덧셈·연결(concatenation) 정의가 없으므로 합류 연산 기호를 만들지 않음. 픽셀 영역의 정확한 공간 대응도 주어지지 않아 새 대응 패턴을 주장하지 않음 |
| PAIR 02 / 03-repeat | 상단 대표 구간과 상세 블록을 확대 안내선으로 연결. 동일 입력의 한 분기점에서 주 경로·우회 경로가 출발. 합산 이후 출력을 수평 정렬 | 상단 전체는 h₀→h₄, 한 번의 상세 블록은 hₜ→hₜ₊₁로 구분. 반복 횟수 ×4와 별도 파라미터 θ₁…θ₄는 유지 |
| PAIR 03 / 06-tokens | 입력 6개에 서로 다른 패턴 부여. 유지되는 1·3·4·6의 패턴을 출력과 하단 vᵢ까지 보존. 집합과 각 vᵢ/wᵢ 쌍의 범위를 프레임으로 표시하고, 화살표를 그 경계에서 시작 | .5·.2·.2·.1의 가중치와 합 1 유지. 표식은 항목 식별이고 작은 막대는 설명용 특징임을 명시 |
| PAIR 04 / 05-panels | Text/Vision encoder 출력을 실제 열/행에 연결. 각 축을 독립된 4개 항목으로 표시. 예제·문구·축에 같은 식별 패턴을 사용. 대각선에 1.3px 테두리와 굵은 수식 적용 | 16개 셀은 Iᵢ·Tⱼ 기호를 유지하며 측정된 유사도나 성능 값을 만들지 않음. 색상 외 테두리로 matched-pair 구조 강조 |

## 파일 보존과 제작

이전 `output/arrows` 네 PPTX의 해시가 지난 검증 당시와 같은지 먼저 확인했다. 중간 수동 편집은 발견되지 않았다. 기존 파일은 덮어쓰지 않고, 같은 내용·크기·색 체계를 기준으로 편집 가능한 새 리비전을 별도 `output/feedback-revision`에 저장했다. 임의의 사람 편집 파일을 보존하면서 부분 수정하는 도구의 기능이 추가된 것은 아니다.

새 제작 예제는 `skills/paper-figure/examples/build-feedback-examples.mjs`에 있다. 기존 풍부한 예제 및 과거 비교 결과는 유지했다. 스킬의 시각 검토 지침에 실제 도형 경계, 집합의 범위, 개요/상세 관계, 항목 식별, 행렬 축 연결, 색 이외의 강조에 대한 확인 항목을 추가했다.

## 확인한 범위

- 4개 모두 native PPTX. 라벨·도형·연결선·행렬 셀·패턴을 이미지로 평탄화하지 않았다.
- 각 파일의 내용 계약, 방향, 그룹, 패키지 무결성, 글꼴·슬라이드 크기 및 Artifact Tool 재불러오기 검사 통과.
- 21개 연결선의 저장된 시작·끝 좌표가 실제 지정 도형의 경계점과 일치하는지 확인. 모든 연결 대상에 보이는 채움 또는 테두리가 존재한다.
- 6개 토큰 표식의 구별 가능성, 유지된 항목의 전후 표식 일치, 가중치 합, 모달리티별 항목과 행·열의 일치, 16개 내적 라벨, 대각선의 비색상 강조를 검사했다.
- 저장된 PPTX를 번들 LibreOffice/PDF/Poppler로 렌더링해 네 장 모두 전체 크기와 게재 폭 177.8mm의 미리보기에서 확인했다. 05의 대각선은 336×200px 흑백 보기에서도 테두리로 구분된다. 이 검사는 반 폭에서 모든 글자가 읽힌다는 뜻은 아니다.
- 기존 21개와 이번 7개를 포함한 **28개 검사 통과**. 스킬 형식 검사도 통과했다.
- 최종 전달 파일은 검증된 두 번째 검토본과 바이트 단위로 동일하다. 이전 네 PPTX도 해시가 유지되었다.

이번 새 리비전으로 PowerPoint 앱의 수동 이동·저장 시험이나 새로운 블라인드 모델 평가는 수행하지 않았다. 따라서 앱 편집 실험이나 독립적인 품질 점수가 새로 확보되었다고 주장하지 않는다. 구조 검사와 제작자의 렌더링 검토는 별개의 근거다.
