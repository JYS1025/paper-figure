# 시각 표현 재설계 · 검증 기록

2026-09-29. 사용자의 “다이어그램만 있고 시각적으로 단순하다”는 피드백에 따른 수정이다. [참고 figure 분석](reference-visual-analysis.md), [이전/수정 비교](../output/gallery-refined.html), [수정 PPTX](../output/refined/).

## 무엇을 바꿨는가

8개 과제를 유지하면서 입력 샘플, 특징 평면, 상태 열, 실제 쌍을 나타내는 패턴/문구, 불규칙 관측과 정렬된 표현을 추가했다. 모두 같은 상자 구도를 따르는 기본값을 없애도록 스킬 지침을 바꿨다. 네이티브 path와 개별 picture를 지원하는 작은 제작 기능을 추가했으며, 이미지 crop이 원시 export에서 사라지는 문제를 실제 저장 파일의 crop metadata로 보정했다.

사진은 NASA/scikit-image의 공개 Eileen Collins 샘플이다. [출처](../skills/paper-figure/assets/SOURCES.md)를 파일과 그림에 기록했다. 사진을 모델에 실행한 결과를 제시한 것이 아니다. 막대·곡선·대응 행렬은 설명용 도식이며, 실제 실험 결과가 아님을 각 그림에 표시했다.

## 결과와 검사 범위

현재 파일은 672×400px, 177.8×105.83mm다. 본문은 주로 9–9.75pt, 작은 주석은 8.25pt, 행렬 표기는 8.625pt다. 한 단 폭으로 그대로 축소하는 것은 검증하지 않았다. 새 버전의 내용 계약 8개, 패키지/크기/폰트/재import 검사 8개를 통과했다.

도형 개수가 많다는 사실은 미적 품질 점수가 아니다. [검사 원본](validation/refined/summary.json)과 각 파일의 finalizer 영수증을 보관했다. 해당 영수증의 SHA-256은 전달 파일과 일치한다.

저장된 최종 PPTX 8개를 Artifact Tool과 번들 LibreOffice/PDF/Poppler로 렌더링했다. 전자를 확대하여, 후자를 672px 게재 폭에서 각각 검토했다. `.png`는 Artifact Tool, `.office.png`와 `.publication.png`는 LibreOffice 경로의 결과다. 확대 이미지와 게재 폭 이미지는 같은 파일의 결과다.

시각 검토에서 02의 crop 소실과 그림/연결선 충돌, 03의 우회선/상태 겹침, 05의 행렬 축 위치와 대비, 06의 연결선 중복/우회, 08의 불필요한 벡터와 갱신선 우회를 수정했다. 04의 공간 평면은 각 단계의 폭·높이가 1/2이 되도록 고쳤다. 채널 개수는 명세가 없어 면의 개수로 주장하지 않는다.

[19개 기능 검사](validation/refined/tests.txt)가 통과했다. 기존 15개에 새 8개 내용 계약, 실제 저장된 사진 crop, 사진/영역 표시를 보존하는 국소 텍스트 수정, 잘못된 사진 순서의 crop 적용 거절을 추가했다. 스킬 공식 quick_validate도 통과했다.

## 남은 확인과 주장 경계

새 버전 전체에 대해 PowerPoint 수동 편집 검사를 다시 수행한 것은 아니다. 02를 실제 앱에서 열어 추가 확인하려 했으나 파일 선택 창의 Open이 비활성화되고 화면 캡처가 빈 화면을 반환하여 확인을 완료하지 못했다. 그 시도를 성공한 검사로 세지 않는다. 이전 버전의 실제 편집·저장·재열기 결과는 [이전 검증 기록](validation-report.md)에 별도로 남아 있다.

고급 Office 수식(OMML), 복잡한 연결선 이동, 연결된 그룹 이동의 제약은 유지된다. 도형과 사진을 함께 쓰는 새 파일에서도 비대상 객체/파트 보존 검사는 통과했다. 사진의 픽셀 자체는 네이티브 도형으로 변환하지 않았으며, 사진 객체의 교체·crop과 주변 라벨/영역 표시를 각각 편집할 수 있는 구조다.

이번 시각 평가는 제작자의 비교 검토다. 독립 모델 4조건 실험, 블라인드 미적 평가, 실제 인쇄물 검사는 하지 않았다. “참고 논문과 동등한 품질” 또는 개선율을 주장하지 않는다. 실제 논문에 사용할 때는 그 논문의 고유 데이터와 명세로 다시 설계해야 한다.
