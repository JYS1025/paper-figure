Generate and inspect the full composition before authoring the PPTX, following [image-first.md](references/image-first.md). Keep the actual prompt, returned image, transfer decisions and draft-to-render comparison. Record `antigravity-native` and provider/model information only when actually known. Native labels, formulas, shapes and connectors remain editable.

Only when the user explicitly requests use or setup of the external Gemini image API, read [the requested integration guide](references/gemini-image-api.md). Until that request, do not expose the option, offer it as a fallback, inspect credentials or run setup. A saved key, an ordinary image request, native-tool failure or exhausted quota is not that request. Reuse the explicit choice within the current task.

If the built-in tool is absent or fails, explain the observed limitation. Continue independent preparation and discuss retrying the existing tool, using a supplied draft or direct native authoring as appropriate; do not introduce an external service. An explicit instruction to skip image generation selects direct native authoring (`no-api` in task notes). Local PPTX edits and supplied-image reconstruction need no new draft or onboarding.
