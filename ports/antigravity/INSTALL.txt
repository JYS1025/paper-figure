Paper Figure — Antigravity CLI 설치·사용 안내
2026-10-01

Antigravity CLI(agy)용 플러그인입니다. 사용 가능한 내장 generate_image를 우선 사용합니다. 계정 로그인으로 사용하는 내장 경로에는 별도 Gemini API 키 등록이 필요하지 않습니다. 별도 Gemini API 연결은 선택 사항입니다.

1. 설치

Antigravity CLI: https://antigravity.google/docs/cli/install
Private 저장소 접근 권한이 있는 Git 인증과 GitHub CLI를 준비합니다.

gh auth login
gh auth setup-git
gh repo clone JYS1025/paper-figure paper-figure
agy plugin install ./paper-figure/ports/antigravity/plugin
agy plugin list

이미 저장소가 있으면 복제 없이 실제 경로를 사용합니다. 플러그인은 ~/.gemini/antigravity-cli/plugins/paper-figure/에 설치됩니다. 새 세션에서 /skills 또는 /plugin으로 확인하고 /paper-figure를 호출합니다. 프로젝트의 .agents/skills/paper-figure가 Codex 버전이면 같은 이름으로 탐색될 수 있으므로 로드된 경로를 확인하세요. 전용 플러그인의 공개 엔진을 사용해야 합니다.

ZIP으로 설치할 경우 압축을 풀고 plugin.json이 있는 폴더를 지정합니다:
agy plugin install /path/to/extracted/paper-figure

2. 제작 방식

새 figure는 현재 세션의 내장 generate_image로 초안을 만든 뒤 편집형 PPTX로 재구성합니다. 실제 도구 제공 여부와 계정 권한·할당량을 확인하며, 내장 경로에서는 API 키를 요구하지 않습니다. 기존 선택은 같은 작업에서 반복해서 묻지 않습니다.

내장 도구를 사용할 수 없거나 사용자가 다른 방식을 원하면 별도 Gemini API 또는 이미지 생성 없는 직접 제작을 선택합니다. 실패했다고 유료 API로 자동 전환하지 않습니다. “API 키 없이”는 내장 이미지 생성 사용과 양립합니다.

별도 Gemini API를 선택한 경우에만: 이미지 모델 초안 → 검토 → 편집형 PPTX 재구성. Google API 키와 모델 접근 권한이 필요하며 API 요금이 발생할 수 있습니다. 키가 없으면 https://aistudio.google.com/apikey 를 안내합니다.

키는 채팅에 보내지 마세요. 설치된 플러그인의 skills/paper-figure 폴더에서 본인의 터미널로:
python3 scripts/gemini_image.py setup

숨김 입력으로 등록하며 프로젝트 밖 개인 설정 폴더에 보관합니다. 기존 환경변수 PAPER_FIGURE_GEMINI_API_KEY, GOOGLE_API_KEY, GEMINI_API_KEY도 지원합니다. python3 scripts/gemini_image.py status는 키 존재 여부만 확인하며 API를 호출하지 않습니다.

이미지 생성 없이 직접 제작: 키 등록 없이 레퍼런스·배색·관계를 검토하고 네이티브 도형·텍스트·수식으로 제작합니다. 제공된 이미지는 별도 그림 객체로 사용할 수 있습니다. 이미지 모델 초안을 생성한 것으로 표시하지 않습니다.

3. 실행 환경

Node.js 20+, PptxGenJS, Python 3.10+, lxml, Pillow, pdfplumber가 필요합니다. 저장된 PPTX 검토에는 LibreOffice/Poppler 등 사용 가능한 렌더러가 필요합니다. 스킬 폴더의 node scripts/preflight.mjs는 의존성과 선택적 API 키 존재 여부만 확인합니다. 내장 도구 제공 여부는 에이전트 세션에서 별도로 확인하며, API 키 미등록은 내장 경로의 실패가 아닙니다.
상세 지침: skills/paper-figure/references/antigravity-environment.md, image-options.md.

4. 업데이트

설치된 플러그인을 직접 수정했다면 먼저 백업하세요. 저장소를 갱신한 후 플러그인을 다시 설치합니다:
git -C paper-figure pull --ff-only
agy plugin uninstall paper-figure
agy plugin install ./paper-figure/ports/antigravity/plugin

키는 플러그인 밖에 보관되므로 패키지에 포함되지 않습니다. 플러그인 ZIP에는 plugin.json과 자체 완결된 skills/paper-figure 폴더가 들어 있습니다.
