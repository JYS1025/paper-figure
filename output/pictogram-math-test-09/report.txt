개선된 paper-figure 스킬 샘플 테스트 · 2026-10-01

샘플: 시각·관성 센서의 지연 보정. 이전 테스트와 같은 설명 대상을 사용하여 픽토그램과 수식 조판 변경을 비교했다. 가상 방법을 설명하는 샘플이며 실측 결과는 아니다.

최종 파일: figure-v4.pptx
미리보기: figure.png
벡터·텍스트 PDF: figure.pdf
설계 폭: 177.8 mm

적용 내용
- 카메라와 관성 센서를 평면 픽토그램으로 생성했다. 각각 독립된 그림 객체로 삽입했다.
- 다이어그램, 화살표, 모든 글자와 수식은 네이티브 객체다.
- 수식 변수와 k는 이탤릭, now·숫자·연산자는 정자로 통일했다.
- 수식 구성 요소를 명시적인 크기로 배치하고 식 단위로 그룹화했다. Office 수식 객체(OMML)는 아니다.
- 원래 상태와 보정 상태를 같은 시간 열에 배치하고, 수식의 + 기호로 흑백에서도 상태를 구별한다.

확인 결과
- 네이티브 도형 107개, 연결선 12개, 그룹 11개, 독립 그림 2개.
- 필수 연결 관계 12개, 내용 계약과 연결점 검사 통과.
- 생성 이미지 2개의 이름·개수·삽입된 원본 파일 일치 확인.
- 실제 PDF 수식 영역 10개 검사: 글꼴 대체, 문자 누락, 크기 기준 경고 0건.
- 주요 상태식: 본문 13.493 pt, 첨자 9.213 pt. 비율 약 68.3%.
- 검사한 전체 수식 중 가장 작은 첨자: 7.710 pt.
- 실제 수식 글꼴: TimesNewRomanPSMT / TimesNewRomanPS-ItalicMT.
- 최종 전체 출력, 출판 폭 미리보기, 흑백 출력 확인.
- 자동 레이아웃 검사에서 꺾인 연결선의 사각 경계와 라벨 사각 경계가 겹친다는 경고 1건이 있었으나 실제 선과 글자는 겹치지 않음을 최종 출력에서 확인했다.

검증은 번들 LibreOffice의 PDF 출력 기준이다. PowerPoint 직접 편집 테스트와 별도 블라인드 평가는 수행하지 않았다. 그림 내부 픽셀은 벡터처럼 편집되지 않으며 각 그림의 이동·교체·크기 변경은 가능하다.
