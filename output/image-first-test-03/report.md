# 이미지 초안에서 편집형 PPTX로 재구성한 시험

같은 액적 선별 요구사항과 `olive-copper` 색상 책으로 내장 이미지 모델의 초안을 만든 뒤, 시각 구도를 참고해 PowerPoint 객체로 재구성했습니다. [이미지 초안](image-draft.png), [재구성한 figure](figure.png), [PPTX](figure.pptx), [PDF](figure.pdf), [실제 이미지 생성 프롬프트](image-prompt.txt)를 제공합니다.

이번 시험은 이 제작 경로가 작동하는지 확인한 예시입니다. 기존 직접 생성 방식보다 더 좋다는 독립 블라인드 결과는 아직 없습니다. 재구성 담당자는 이전 대화와 피드백을 알고 있었으며, 초안의 오류를 수정하고 종횡비도 조정했습니다. 동일 시간·프롬프트·수정 예산을 맞춘 통제 실험이 아닙니다.

후속으로 [내부 라벨을 유지한 실제 논문과의 블라인드 비교](../image-first-blind-test-04/report.md)를 수행했습니다. 새 맥락의 검증 두 곳 모두 실제 논문을 맞혔지만 전체 시각 품질은 이 생성본을 선호했습니다. 한 쌍이며 내용 범위가 다르고, 동일 모델 설정을 상속한 평가이므로 직접 생성 방식 대비 우위를 입증하지는 않습니다. 평가 전후 figure 파일은 동일합니다.

## 초안에서 보존한 시각 선택

- 가로로 길게 이어지는 하나의 장치 구도와 구간별로 달라지는 밀도.
- 조밀한 배양 채널, 검출 위치를 표시하는 장치 형태, 위쪽에 분리한 제어 영역.
- 단계의 범위를 보여주는 괄호, 짧은 라벨과 지시선, 넓은 면과 작은 강조점의 구분.

## 그대로 옮기지 않은 부분

| 이미지 초안의 문제 | PPTX에서의 처리 |
|---|---|
| Controller와 Compare F with θ가 별도 상자로 나뉘고 신호가 병렬로 연결됨 | 비교 기능을 Controller 내부에 넣고 검출→제어→전극 관계로 정리 |
| 수성 유입부에 브리프가 요구하지 않은 입자 같은 표식이 있음 | 연속 수성 유입부로 표현하고, 형성 이후에만 액적을 표시 |
| flow focusing의 오일 공급과 좁아지는 관계가 모호함 | 위·아래 오일 공급이 수성 유입부를 만나도록 재구성 |
| 양쪽 출구에 비슷한 액적을 쓰고 상단 채널 색도 달라짐 | 운반유 색은 유지하고, 채운 원과 빈 원 및 부등식으로 두 선별 결과를 구분 |
| 판정 전 표식의 의미가 명시되지 않음 | Unscored 범례를 추가하고 검출 전 표식에 일관되게 사용 |

## 편집 가능성과 확인 범위

최종 PPTX에는 native shape 87개, native connector 2개, group 1개가 있습니다. 삽입된 picture와 미디어 파일은 0개입니다. 전체 초안을 그림 한 장으로 넣지 않았으며 라벨, 액적, 채널 윤곽, 제어선은 각각 수정할 수 있습니다. 복잡한 채널은 사용자 지정 경로이므로 형태를 바꿀 때는 경로의 점을 편집해야 합니다.

저장 PPTX의 필수 내용·연결 검사와 패키지 검사를 통과했습니다. 번들 LibreOffice에서 PDF로 변환한 뒤 PNG를 만들고, 전체 크기·게재 폭에 해당하는 보기·흑백 보기를 검토했습니다. 그 과정에서 라벨과 제어선의 겹침을 정리하고, 원형 그라데이션의 렌더링 손실을 단순한 native 채움으로 바꿨습니다. PowerPoint 실앱에서 직접 편집하는 테스트는 수행하지 않았습니다.

## 스킬에 반영한 방식

`이미지 초안 → 내용 명세와 대조 → 보존/수정/변환 계획 → native PPTX 재구성 → 의미와 시각 전달을 각각 검토`하는 선택 경로를 추가했습니다. 간단한 그림이나 작은 수정까지 이미지 생성을 강제하지 않습니다. 이미지 초안의 미관과 PPTX가 보존한 시각 품질, 기존 직접 생성 방식 대비 우위는 서로 다른 평가 항목으로 취급합니다.

전체 미관은 개선될 가능성이 있지만, 이 시험에서 확실히 확인한 것은 **시각 초안을 참고하면서 의미상의 오류를 고치고 편집형 객체로 재구성할 수 있다는 점**입니다. 이미지의 모든 질감을 그대로 유지하거나 직접 생성보다 우수하다는 결과를 주장하지 않습니다.
