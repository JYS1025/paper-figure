BSAE 프로젝트 figure 샘플

현재 로컬 BSAE 프로젝트의 확장 기본 구조를 표현했다. 인코더는 1024→1024→768→512→256→128→32, 디코더는 32→128→256→512→768→1024→1024이며 각 공유 단계는 Linear+LIF다. 입력 어댑터와 유효 채널 마스크는 인코더 앞에만 놓았다. 잠재 표현과 복원 출력은 이진 스파이크다.

학습 경로는 어댑터 전 원본 타깃에만 학습 가능한 채널별 causal delay를 적용한다. 복원 신호는 지연 단계를 통과하지 않는다. 두 신호에 같은 지수 커널을 full convolution으로 적용한 후 평균제곱차를 계산한다. 현재 설정의 지연 범위 0–30 bins와 30 zero-tail bins를 표시했다. 실제 손실은 배치, 전체 1024채널, 전체 필터 시간축을 대상으로 한다. 그림의 일부 채널과 파형은 설명용이며 실제 기록이나 모델 출력, 성능 비교 결과가 아니다.

진행 증거
content-contract.json과 source-evidence.json에 내용과 원본 파일 해시를 기록했다. U-Net 원본 figure를 열어 압축·확장 구조의 표현을 검토했다. imagegen으로 전체 초안을 생성한 실제 프롬프트는 draft-prompt.txt, 선택한 초안은 selected-draft.png다. 이를 직접 확인한 뒤 PPTX 작성 전에 transfer-plan.txt를 기록했다. 신경 기록 아이콘은 별도 imagegen 호출로 생성했고 assets 폴더에 원본과 프롬프트를 보존했다.

초안에서 유지한 것은 위쪽 모래시계형 압축·복원 구조, 청록/금색/코럴의 역할 구분, 아래쪽 두 학습 경로와 공통 손실, 마지막 한 채널 지연 예시다. 초안의 잘못된 층 수, 임의의 초 단위 축, 현재 데이터에 맞지 않는 뇌/삽입형 프로브 아이콘은 수정했다. 필터마다 반복되던 여러 채널 그림은 단일 설명용 파형으로 정리하고 전체 세로 공간을 조금 늘렸다. 입력 스파이크가 뒤쪽 시간 칸에 0.2/0.5/0.3으로 분배되는 예시는 동일한 진폭 척도를 사용한다. 전체 초안은 최종 PPTX에 포함하지 않았다.

검사 결과
최종 figure-v3.pptx를 번들 LibreOffice로 PDF/PNG 렌더링했다. 본문 폭 177.8mm 및 흑백 출력에서 단계, 두 학습 경로, 인용 없는 설명용 예시를 확인했다. draft-vs-pptx.png는 같은 폭의 초안/최종 렌더 비교다. 최종본에서 초안의 구도와 주요 표현이 유지되며, 글자/도형 충돌과 손실 입력 접점 문제를 수정했다.

실제 저장 객체: native shape 196개, connector 10개, group 16개, 독립 picture 1개. 인코더/디코더의 채널 수는 프로젝트 소스와 일치한다. 10개 연결의 방향과 보이는 경계 접점을 확인했다. 지연 예시의 네이티브 막대 높이와 가중치를 비교했고, 필터 파형의 저장 좌표를 직접 convolution 결과와 대조했다. 포함된 유일한 raster는 별도 신경 기록 아이콘이다.

수학 표기 14영역에서 실제 Times New Roman 렌더 폰트와 크기를 확인했다. 첨자·hat을 포함한 최소 수학 글자는 8.306pt다. 초기에 넓게 잡은 영역 5개가 주변 제목/푸터의 Arial 글자를 경계에서 잡아냈으므로, 실제 PDF 글자 위치와 최종 렌더를 확인하여 수학 영역을 좁혀 재검사했다. 허용 폰트·기대 문자·크기 기준은 변경하지 않았다. 최종 수학 검사에서 누락 문자나 예상 밖 폰트는 없었다.

문자, 수학 기호, 스파이크, 층 도형, 파형과 연결선은 편집 가능한 native 객체다. 그림 아이콘은 독립 이동·크기 조절·교체가 가능하며 내부 픽셀은 벡터 부품이 아니다. 수식은 그룹화한 네이티브 텍스트이며 OMML이 아니다. PowerPoint 직접 편집 시험과 독립 검증모델의 블라인드 평가는 수행하지 않았다.
