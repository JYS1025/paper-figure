# 비동기 재료 탐색 그림 제작 보고

완료본은 `figure.pptx`, 저장된 PPTX에서 렌더한 `figure.pdf`와 `figure.png`입니다. 실제 image_gen 초안은 `image-draft.png`, 사용한 전체 프롬프트는 `image-prompt.txt`에 보존했습니다. 원문 브리프도 `brief.md`로 복사했습니다.

그림은 177.8 × 155.575 mm, 1쪽입니다. 영어 라벨은 native PowerPoint 텍스트이며 후보, 집합 경계, 운영 상태, 화살표도 각각 편집 가능한 객체입니다. 저장 파일은 native 도형 46개, native connector 11개로 구성되며 그림 객체·SVG·평탄화된 배경은 없습니다. 본문과 보조 라벨은 Arial이며 최소 크기는 7.58 pt입니다.

## 의미와 표현

상단은 선택 순간입니다. 완료된 A와 C만 surrogate를 학습시키고, 선택 단계는 모델 예측, 미실험 E/F, 진행 중 B/D registry를 함께 고려합니다. 선택된 E는 두 station이 모두 사용 중이므로 queue에 남습니다. 선택이 실제 성능 우위를 뜻하지 않는다는 문구를 그림 안에 넣었습니다.

하단은 B가 끝난 이후를 보여 줍니다. B 측정값이 A/C/B 완료 데이터에 추가되고 모델이 갱신될 수 있습니다. 빈 station 1은 E를 시작하지만 station 2는 D를 계속 수행합니다. 최종 registry는 E/D이고 F는 미실험 상태로 남습니다. `Station 1 freed` 화살표는 장비 사용 가능 상태의 변화를 뜻하며, B의 측정 데이터는 위쪽 완료 데이터 집합으로 별도로 전달됩니다. 시간 길이와 점수는 정하지 않았습니다.

moss-clay 색 책에서 moss는 완료 측정, clay는 진행 중, slate는 대기열에 배정했습니다. 일반 연산과 구조는 중립색입니다. 색은 후보 성능이나 재료 클래스를 뜻하지 않습니다. 각 상태에 명시적 단어를 넣어 흑백에서도 읽히게 했습니다.

## 이미지 초안에서의 이전과 수정

실제 초안의 상단 결정 구조, 하단 두 station 경로, 문자 타일, 상태별 집합, 모델 위·선택 아래의 관계를 유지했습니다. [원본 MAE 그림](https://arxiv.org/html/2111.06377v3/arch.png)은 반복되는 항목의 정체성과 처리 상태를 연결하는 원칙을 확인하는 데만 사용했고, 구도를 복사하지 않았습니다.

초안은 완료 데이터 속 B를 여전히 pending 색으로, 실행 중 E를 queued 색으로 표현했습니다. native 그림에서는 완료 B와 pending E를 올바른 상태로 바꾸었습니다. 초안에 빠져 있던 E queue→station 1 dispatch와 B 측정→완료 데이터 연결도 추가했습니다. D의 경로를 가로지르지 않도록 완료 집합은 B 위로 옮겼고, registry 갱신은 `Remove B; register E` 문구와 E/D의 명시적 후속 상태로 나타냈습니다. 넓은 둥근 패널 배경은 얇은 구분선으로 단순화했습니다.

## 검증 결과

내용 계약은 그리기 전에 작성했습니다. 최종 저장 PPTX를 `pptx.py inspect --contract`로 검사했으며 지정된 라벨, native-only 조건, 11개 방향 연결이 모두 일치했습니다. `flow_audit.py`의 연결점 검사는 11개 모두 확인했고, 추가 렌더 검토 플래그와 미확인 기하가 0개였습니다. Presentations 최종화의 패키지·레이아웃·글꼴 정책·재가져오기도 통과했으며 최종 레이아웃 오류와 경고는 0개입니다.

자동 검사는 미관의 증거와 분리했습니다. 저장 PPTX를 번들 LibreOffice로 PDF 변환한 뒤 전체 크기 200 dpi PNG, 게재 폭 177.8 mm에 해당하는 96 dpi PNG, 같은 폭의 흑백 PNG를 직접 확인했습니다. 1차 검토에서 dispatch 선이 `Both stations occupied` 문구를 가로지르는 겹침을 발견해 문구를 E queued 내부로 옮기고 선을 수직 정렬했습니다. 2차 최종 검토에서는 해당 겹침, 글자 잘림, 잘못된 연결 끝점이 보이지 않았습니다. 흑백에서 색조 일부는 비슷해지지만 Completed / Measured / Pending / queued / Untested라는 단어와 집합 라벨로 모든 핵심 상태가 구별됩니다.

## 한계

실제 PowerPoint 앱에서 열거나 객체를 이동하는 편집 시험은 수행하지 않았습니다. native 편집 가능성은 저장 PPTX의 객체와 연결 정보를 확인한 범위에서만 진술합니다. 미리보기는 PowerPoint 스크린샷이 아니라 번들 LibreOffice 렌더입니다. 실물 인쇄 검수는 하지 않았고, PDF의 물리 크기와 96 dpi 게재 폭 렌더로 확인했습니다. 177.8 mm보다 작은 게재 폭은 검증하지 않았습니다. 자동 검사 통과를 정량적인 미적 품질 점수로 주장하지 않습니다.
