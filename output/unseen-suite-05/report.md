# 업데이트한 스킬로 생성한 새 과제 세 개

라벨 공개 블라인드 평가의 남은 피드백을 스킬에 반영하고, 이전 액적 선별 과제와 다른 주제 세 개를 새 맥락에서 생성했습니다. 각 결과는 **이미지 모델 초안 → 내용 명세와 대조 → 편집형 PPTX 재구성 → 저장 파일 렌더링 검토**를 거쳤습니다.

[세 결과와 이미지 초안을 함께 보기](index.html)

## 반영한 기준

- 결정 기호와 상태의 의미는 그림 또는 인접 캡션에서 정의합니다. 이번처럼 단독 사용 그림에는 필요한 정의를 그림 안에 넣습니다.
- 미측정·대기 상태와 음성·빈 상태를 혼동하지 않도록 게재 폭 및 흑백에서 점검합니다. 색을 없애도 라벨·위치·경계·빗금 등의 역할이 유지되는지 봅니다.
- 지연된 측정이나 작동의 시간 대응은 실제 방법에 명시되고 설명에 필요한 경우에만 표시합니다. 단순히 두 장치가 떨어져 있다는 이유로 시간 보정 모듈을 만들어 넣지 않습니다.

추가 생성 과정에서 수식 인덱스가 `a_ci`, `t_now`처럼 코드 표기로 남은 사례를 발견했습니다. 두 생성자에게 native 아래첨자로 정리하도록 요청했고, 이 관찰도 최종 스킬의 수식 작성 지침에 반영했습니다. 새 수학 기호나 방법을 추가한 것은 아닙니다.

## 초안을 옮기며 확인한 점

시간 지연 과제는 초안의 과거 상태·보관된 측정·보정 후 상태를 연결하는 구도를 활용했습니다. 초안에서 관측 시점 이전까지 보정되는 것처럼 보이는 표현과 중복 replay 경로를 정리했습니다. 최종본에서는 보정 대상인 과거 상태와 최종 출력인 현재 자세를 구분합니다.

공간 집계 과제는 큰 공간 예시, 오른쪽 행렬, 하단 두 출력식의 구도를 유지했습니다. 미할당 비중을 세포 행렬 A의 바깥으로 분리하고 빗금으로 정의했습니다. S2의 가중치는 두 세포에 나뉘고, S4의 바깥 부분은 보존되며, S5는 어느 세포에도 기여하지 않습니다. spot 인덱스와 feature 인덱스도 구분했습니다.

비동기 실험 과제는 상단 선택 단계와 하단의 독립 station 경로를 유지했습니다. 이미지 초안에 남아 있던 완료 B·실행 중 E의 잘못된 상태색을 고치고, 대기열 E의 dispatch와 B 측정값의 완료 데이터 전달을 연결했습니다. 완료 A/C/B, 실행 중 E/D, 미실험 F가 각각 명시됩니다.

이 사례들은 이미지 초안이 구도 참고에는 도움이 되지만, 상태·집합·시간 관계를 그대로 믿고 옮길 수는 없음을 보여줍니다. 시각적 설계 선택은 살리고 의미상의 오류를 수정했습니다. 기존 직접 제작법보다 우수하다는 비교 결과는 아닙니다.

## 검토 범위

각 생성자는 내용을 그리기 전에 명세로 정리하고, 저장된 PPTX의 필수 라벨·연결·객체 구조 검사와 최종화 검사를 수행했습니다. 최종 PNG는 저장 PPTX를 번들 LibreOffice로 렌더링한 결과입니다. 전체 크기, 게재 폭에 대응하는 축소 보기, 흑백 보기를 검토했습니다. 부모 세션도 세 최종 렌더와 핵심 의미 관계를 확인했습니다.

부모의 검토에서는 공간 집계 수식의 아래첨자, 비동기 dispatch 선의 문구 겹침, 시간 표기의 아래첨자 일관성을 짚었습니다. 생성자가 자신의 파일에서 수정하고 다시 렌더링했습니다. 공간 수식과 dispatch 겹침은 생성자 자체 검토에서도 확인한 사항이었습니다. 따라서 최종본은 새 맥락에서의 최초 생성에 후속 검토가 더해진 결과입니다.

라벨·도형·수식 텍스트·연결은 native 객체로 남아 있습니다. 전체 이미지 초안을 삽입한 한 장짜리 그림으로 대체하지 않았습니다. 실제 PowerPoint 앱에서 객체를 움직이고 다시 저장하는 시험은 하지 않았습니다. 편집 가능성의 근거는 저장 객체 구조와 import 검사이며, 미리보기는 PowerPoint 스크린샷이 아닙니다.

## unseen의 의미와 평가 한계

세 과제는 이 프로젝트의 기존 예시 목록과 앞선 액적 선별 과제에 없는 새 내용입니다. 생성자는 이전 대화·완성 예시·평가 원문을 받지 않고 자신의 브리프와 갱신된 스킬만으로 시작했습니다. 스킬이 가리키는 원본 논문 그림과 구현 지침은 참고할 수 있었습니다. 모델 학습 데이터에 없는 과제라고 주장하지 않습니다.

과제는 앞선 피드백을 알고 있는 부모 세션이 작성했습니다. 생성자는 모두 같은 부모 모델 설정을 상속한 새 맥락이며 다른 모델 서비스가 아닙니다. 이번 실행은 새 과제의 생성과 내용·렌더링 검토이며, 출처 맞히기 블라인드 테스트나 제작 경로 간 통제 실험은 아닙니다.
