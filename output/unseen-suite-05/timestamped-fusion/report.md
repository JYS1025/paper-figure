# Timestamped visual–inertial state correction

## 그림 설명

플랫폼의 시각 관측은 촬영 시각 `tₖ`를 유지한 채 시각 추정기로 전달됩니다. 그 결과가 도착하는 동안 관성 전파는 `t_now`까지 진행합니다. 파란 반환 경로는 늦게 도착한 보정이 버퍼의 `s(tₖ)`를 대상으로 삼는다는 점을 나타냅니다. 이 상태를 `s⁺(tₖ)`로 갱신한 뒤, 버퍼에 보관한 `(tₖ, t_now]` 구간의 관성 측정을 재생합니다. 최종 전달 값은 구리색으로 강조한 현재 포즈 `s⁺(t_now)`이며, 이후 전파는 여기서 이어집니다.

시각 관측, 샘플 수, 시간 간격은 개념적 표현입니다. 지연 수치, 주파수, 이동 궤적 또는 정확도를 제시하지 않았습니다. 게이트, 지도 갱신, 추가 센서, 동기화 알고리즘을 추가하지 않았습니다.

## 제작 경로와 초안 이전 판단

1. 브리프에서 내용 계약과 관계 계획을 먼저 작성했습니다. 원본 브리프는 `brief.md`로 복사했습니다.
2. `paper-figure`, `imagegen`, `Presentations` 스킬을 읽고 built-in `image_gen`으로 실제 이미지 초안을 생성했습니다. 정확한 생성 프롬프트는 `image-prompt.txt`, 선택한 초안은 `image-draft.png`입니다.
3. 초안의 상단 센서/추정 경로, 하단의 넓은 버퍼, 위아래 상태 대응, 과거로 돌아가는 보정 경로, 현재로 나아가는 구리색 재생 경로를 유지했습니다.
4. 초안이 `tₖ` 이전의 상태까지 보정된 것으로 그린 오류를 제거했습니다. 중복된 재생 경로는 수정된 과거 상태와 보관 측정을 입력으로 받는 하나의 `Replay` 연산으로 정리했습니다. 출력 설명이 출력 상태에 입력되는 것처럼 보였던 화살표를 없애고 현재 출력에 직접 캡션을 붙였습니다.
5. 초안의 사실적인 쿼드콥터는 플랫폼 종류를 임의로 지정하므로, 센서 포트를 포함한 native 플랫폼 경계로 바꿨습니다. 원형 상태는 native 연결점 검증이 가능한 사각형으로 옮겼습니다. 그림의 모든 라벨, 상태, 측정 표시, 연산, 연결선은 개별 편집 가능한 PowerPoint 요소입니다.
6. `Figure` 도우미와 Artifact Tool로 작성하고 Presentations finalizer를 실행했습니다. 현재 상태에 들어가는 꺾은선은 생성 단계에서 표준 OOXML `bentConnector2`로 교정했습니다. 그 뒤 저장 파일을 다시 검증했습니다.

색상 책은 `olive-copper`입니다. 관성 측정/전파는 올리브, 시각 추정/역시점 보정은 파랑, 갱신 및 재생 상태는 구리색에 대응합니다. 기본 구조와 원래 상태는 회색입니다. 색 이외에도 상태 기호, 행 위치, 테두리 굵기를 유지했습니다.

원본 참조로 [MAE architecture](https://arxiv.org/html/2111.06377v3/arch.png)를 브라우저에서 직접 보았습니다. 반복 항목의 정체성과 표현 상태를 유지하는 원리를 참고했으며, 원본 구도나 이미지를 복사하지 않았습니다. 팔레트 책의 Mamba 관련 설명은 읽었지만 원본 SVG는 웹 추출에서 열리지 않았으므로 직접 시각 검토했다고 주장하지 않습니다.

## 최종 저장 파일의 검증

- 1슬라이드, 672 × 454 CSS px. 물리적 크기 177.8 × 120.12 mm.
- 57개 native 도형, 12개 native 연결선, 2개 native 그룹. 이미지 및 SVG 객체 0개.
- 최종 `figure.pptx`에 대한 `pptx.py inspect --contract`: 통과, 오류 0, 경고 0. 내용 계약의 정확한 라벨·방향·그룹을 검사했습니다.
- 최종 `flow_audit.py`: 12개 연결선 모두 지원 형상과 가시 경계로 검사됨. 좌표 오차 경고 0, 수동 확인 필요 플래그 0.
- Presentations finalizer: 패키지 무결성, 슬라이드 크기, 지정 Arial 폰트, Artifact Tool 재임포트 검사 통과.
- finalizer의 `connector_over_text` 경고 2건은 파란 꺾은선 전체 경계상자와 `advances to t_now`, `State and measurement buffer` 텍스트상자의 교차입니다. 실제 선은 이 글자들을 통과하지 않음을 저장 PPTX의 렌더에서 확인했습니다.
- PDF/PNG는 번들 LibreOffice로 최종 저장 PPTX에서 변환했습니다. 독립된 작업용 프로필을 사용했고 사용자 데스크톱 LibreOffice는 사용하지 않았습니다. PNG는 300 dpi, 2100 × 1419 px입니다.

## 시각 검토와 수정

저장 PPTX의 전체 렌더, 177.8 mm에 대응하는 96 dpi / 672 px 렌더, 같은 크기의 흑백 렌더를 각각 확인했습니다. 초기 센서 라벨 넘침, 현재 상태를 관통하던 화살표, 보정 경로와 작은 설명문이 겹치던 부분을 수정했습니다. 최종본에서 과거 시점과 현재 출력의 대응, 재생에 들어가는 측정 집합의 범위, 화살표의 종점, 미래 전파의 출발점을 추적했습니다.

보정/관성 경로의 상단 직교 교차에는 접합점 표시가 없으며, 각각의 종점은 과거 상태와 현재 상태로 분리됩니다. 흑백에서도 행과 `s`/`s⁺` 표기가 상태 차이를 유지합니다. 현재 출력은 굵은 경계와 굵은 기호를 함께 사용합니다. 자동 검사 통과는 미관의 증명이 아니며, 이 판단은 실제 렌더를 별도로 읽고 내린 것입니다. 최종 교차 검토에서 발견한 `t_now`의 밑줄 표기는 다섯 위치 모두 native 아래첨자 `now`로 통일했고, 저장 파일을 다시 렌더하여 확인했습니다. 독립 심미 평가나 직접 native 제작 대비 우월성 실험은 수행하지 않았습니다.

## 한계

실제 PowerPoint 앱에서 열어 객체를 이동하거나 텍스트를 편집하는 시험은 하지 않았습니다. 파일의 native 객체 구조와 LibreOffice 렌더만 검증했습니다. 수식 표기는 편집 가능한 Unicode 및 native 아래첨자 텍스트 run이며 OMML 수식 객체가 아닙니다. 화면의 672 px 검토는 물리적 출력물의 실측 검사가 아닙니다. 이 그림은 177.8 mm 전폭용으로 제작했으며 단일 열로 축소한 가독성은 보장하지 않습니다.

필수 결과물: `figure.pptx`, `figure.png`, `figure.pdf`, `image-draft.png`, `image-prompt.txt`, `result.json`, `report.md`.
