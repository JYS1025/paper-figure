위 판별을 먼저 확정한 뒤 아래 수정 의견을 작성했다. 확신도는 보정된 확률이 아닌 주관적 추정이다. 네 쌍 모두 구도에 대한 기억이 출처 판단에 영향을 주었으며, 특정 원본과 일치하는지 확인하지 않았다. 아래 완성도 평가는 그 기억과 별개로, 화면에 보이는 형태·상태 변화·연결·대응 관계를 근거로 한다. 회색 가림막의 모양·개수·크기·누락은 평가 근거에서 제외했다.

**Pair 01 — 출처 추정 B, 시각적 완성도 B**

B의 왼쪽 하강부와 오른쪽 상승부에서는 블록의 높이와 가로 폭이 함께 변하고, 같은 높이의 좌우 단계가 수평 연결로 대응한다. 아래로 이동하는 붉은 화살표, 위로 이동하는 녹색 화살표, 단계 내부의 짙은 파랑 화살표가 반복되어 경로의 역할을 구분해 볼 수 있다. 정확한 연산명은 가려져 있어 판단하지 못하지만, 서로 다른 종류의 이동이 있음을 그림 자체가 전달한다. A도 큰 격자에서 작은 격자로 줄었다가 커지는 흐름과 좌우 대응이 명료하다. 다만 가장 아래의 작은 적층체와 주변 선 사이의 연결, 오른쪽에서 두 경로가 어떻게 합쳐지는지는 B보다 덜 명시적이다. 도형 수가 많다는 이유로 B를 높게 평가한 것은 아니다.

생성본으로 추정한 A의 약점은 다음 세 가지다.

1. 아래 중앙의 작은 적층체 주변 → 왼쪽 파란 화살표 끝과 적층체, 적층체와 오른쪽 녹색 선 시작 사이에 상당한 간격이 있음 → 이 적층체가 주 경로의 한 단계인지 독립된 설명용 아이콘인지 연결만으로 확정하기 어렵다.
2. 오른쪽 큰 격자와 중간 격자 → 주황 점선은 왼쪽 면으로, 녹색 주 경로는 아래쪽으로 들어오지만 두 입력의 결합 방식은 형태로 드러나지 않음 → 단순 전달, 더하기, 이어 붙이기 중 무엇을 표현하는지 도형만으로 구별할 수 없다. 실제 방법에 결합 연산이 있는지는 확인이 필요하다.
3. 좌우 격자와 단계 사이 → 격자의 전체 크기는 변하지만 연산은 대부분 선으로만 표현됨 → 해상도 변화 자체는 보이는 반면, 그 사이에서 무엇이 바뀌는지에 대한 설명은 텍스트에 크게 의존한다. 이 그림이 개념 개요라면 허용될 수 있지만, 구조를 설명하는 주 figure라면 구체성이 부족하다.

개선 우선순위는 다음과 같다.

1. 아래 중앙 적층체의 좌우에 입·출력 접점을 정하고 주변 선을 그 접점까지 연결한다 → 경로의 연속성을 확보한다 → 왼쪽 입력에서 오른쪽 출력까지 어느 선이 어느 도형에 연결되는지 중간 추측 없이 추적할 수 있으면 완료다.
2. 실제 방법에서 두 입력을 합치는 연산이 있다면 오른쪽의 합류 지점에 해당 연산의 작은 기호 또는 명확한 두 입력 포트를 둔다 → 우회 연결의 처리 방식을 구분한다 → 각 합류 지점에서 입력 수와 결합 위치가 일관되게 읽히고, 기호가 확인된 실제 연산과 일치하면 완료다. 연산을 확인하지 않고 더하기 기호 등을 추가하지 않는다.
3. 이 그림이 연산 구조까지 설명해야 한다면 각 축·적층 두께가 나타내는 양을 확인하고, 실제로 변하는 속성만 크기·격자·적층 표현에 반영한다 → 장식적인 크기 차이를 정보가 있는 상태 변화로 만든다 → 같은 속성에는 같은 시각 규칙이 적용되고 좌우 대응 단계의 관계가 설명과 맞으면 완료다. 임의의 채널 수나 단계는 만들지 않는다.

화살표만 두껍게 바꾸면 해결되지 않는다. 상대적 굵기에서는 A의 파랑·녹색 실선이 격자 외곽선보다 이미 뚜렷하고 주황 점선도 식별 가능하다. 화살촉 크기는 현재 방향을 읽는 데 큰 문제가 없다. 연결 지점에서는 아래 중앙의 간격과 오른쪽 합류의 의미가 더 중요한 문제다. 경로는 U자 흐름과 수평 대응을 잘 분리해 교차가 거의 없다. 역할별로 실선과 점선이 구분되지만, 점선의 정확한 연산 의미는 확인할 수 없다. 굵기 증가는 이 의미와 접점 문제를 해결하지 못한다.

**Pair 02 — 출처 추정 A, 시각적 완성도 비슷함**

A의 아래쪽 원형 합산 기호와 파형 모양, 블록 옆으로 돌아오는 우회선, 왼쪽 스택에서 오른쪽 스택으로 들어가는 연결은 서로 다른 입력·경로를 공간적으로 표현한다. 같은 색의 블록이 반복되는 위치도 안정적이다. 반면 두 스택 사이의 연결과 우회선이 밀집하여 경로를 읽는 데 주의가 필요하다. B의 아래쪽에서는 점선 우회 경로와 두 상자를 거치는 주 경로가 더하기 기호로 합쳐져, 한 블록의 내부 흐름을 쉽게 추적할 수 있다. B의 위쪽 순차 개요와 아래쪽 상세 그림의 대응은 약하다. 따라서 A의 관계 표현과 B의 국소 경로 가독성을 함께 고려해 비슷함으로 평가했다.

생성본으로 추정한 B에서는 다음 두 가지를 주요 약점으로 판단했다. 세 번째 결함을 억지로 추가하지 않는다.

1. 위쪽 가로 흐름과 아래쪽 큰 상세 상자 사이 → 어느 위쪽 구간을 아래에서 풀어 설명하는지 연결선·확대 표시·공통 테두리로 드러나지 않음 → 개요와 상세를 하나의 설명으로 결합하려면 가려진 라벨을 읽어야 한다.
2. 위쪽의 연속된 작은 막대 묶음 → 높이는 조금씩 바뀌지만 동일한 형식이 유지되며 단계별 변화가 주로 미세한 높이 차이와 마지막 색 변화에 한정됨 → 어떤 종류의 변환이 일어났는지 시각적 구별력이 약하다. 단, 실제 의도가 동일 형식의 상태가 점진적으로 변하는 모습을 보여 주는 것이라면 이 표현은 적절할 수 있다.

개선 우선순위는 다음과 같다.

1. 아래 상세도가 위쪽의 특정 단계 또는 반복 단위를 설명한다면 해당 구간에 얇은 괄호나 공통 강조 표시를 두고 상세 상자와 대응시킨다 → 두 수준의 설명을 결합한다 → 라벨을 읽지 않아도 확대 대상의 범위를 하나로 지목할 수 있으면 완료다. 별개 설명이라면 잘못 연결하지 않고 별개임을 구성으로 드러낸다.
2. 위쪽 각 단계의 실제 변환을 확인하고, 그 차이를 설명하는 데 필요한 경우에만 분할·선택·결합·상태 변화 중 해당하는 시각 표현을 추가한다 → 단계의 역할을 형태로 전달한다 → 표시한 변화가 실제 방법에 존재하고, 단계별 차이를 막대 높이의 미세한 차이에만 의존하지 않고 읽을 수 있으면 완료다.
3. 위쪽 막대 높이가 실제 수치인지 개념적 예시인지 확인한다. 실제 값이라면 공통 기준을 유지하고, 개념적 예시라면 불필요한 수치 해석을 유도하지 않도록 상태 표현 규칙을 통일한다 → 작은 막대 그래프가 전달하는 의미를 명확히 한다 → 같은 높이·색의 변화가 모든 단계에서 같은 뜻을 가지며, 표현 이상의 수치나 성능을 암시하지 않으면 완료다.

화살표만 두껍게 바꾸면 해결되지 않는다. 상대적 굵기에서는 B 아래쪽 짙은 실선이 상자 테두리보다 충분히 강하고, 위쪽의 가는 회색 화살표도 방향을 읽을 수 있다. 화살촉은 상자 크기에 비해 과도하지 않고 수신 방향을 식별할 수 있다. 연결 지점에서는 두 실선 입력과 점선 입력이 더하기 노드에 명확히 도달한다. 경로에서는 아래쪽의 직각 복귀선이 교차를 피하며, 더하기 뒤 출력선의 기울기는 치명적인 결함은 아니다. 역할 구분은 아래쪽 실선과 점선에서 유효하다. 이 장점을 유지하면서 개요와 상세의 대응, 상태 표현을 먼저 개선해야 한다.

**Pair 03 — 출처 추정 A, 시각적 완성도 A**

A는 왼쪽의 일부만 드러난 격자, 세로로 나열한 패치, 중간의 토큰 열, 오른쪽의 전체 격자를 통해 입력의 일부가 선택되어 처리되고 다시 전체 형태로 돌아가는 관계를 보여 준다. 사진을 썼다는 사실보다, 입력과 출력이 같은 공간 격자를 공유해 변화의 대상과 결과를 대조할 수 있다는 점이 장점이다. B도 위쪽의 카드열과 아래쪽의 별도 흐름을 분리했지만, 상하 관계를 잇는 파란 선의 출발 대상과 아래쪽 주황 화살표가 받는 항목 범위가 모호하다.

생성본으로 추정한 B의 약점은 다음 세 가지다.

1. 위쪽 오른쪽 카드열에서 아래쪽 녹색 상자로 내려오는 파란 선 → 선이 카드의 경계나 카드열을 묶는 괄호가 아닌 카드 사이 아래 빈 공간에서 시작함 → 특정 카드, 카드열 전체, 중간 결과 중 어느 것을 전달하는지 불명확하다.
2. 아래쪽의 네 막대 묶음과 그 아래 연한 주황 상자들, 오른쪽으로 향하는 주황 화살표 → 항목들을 모으는 선이나 외곽 묶음 없이 화살표가 오른쪽 빈 공간에서 시작함 → 네 항목 전부가 다음 연산에 들어가는지, 마지막 항목만 들어가는지 관계를 눈으로 추적하기 어렵다.
3. 위쪽 입력·출력 카드와 아래쪽 항목 사이 → 공통된 작은 막대 표현은 있으나 항목별 대응을 확인할 수 있는 지속적인 시각 식별자가 부족함 → 항목의 선택·유지·재배열을 설명하려는 그림이라면 그 대응을 확인하기 어렵다. 해당 대응 자체가 설명 목적이 아니라면 이 문제의 우선순위는 낮아진다.

개선 우선순위는 다음과 같다.

1. 파란 하향 화살표가 받는 실제 결과를 확인하고, 단일 카드면 그 카드 경계에, 집합이면 카드열을 묶는 괄호 또는 공통 출력 포트에 시작점을 붙인다 → 상하 흐름의 출처를 명확히 한다 → 선을 역으로 따라갔을 때 하나의 입력 대상을 지목할 수 있으면 완료다.
2. 아래쪽 항목들이 함께 입력되는 것이 맞다면 해당 항목들을 묶는 얇은 경계 또는 집계 접점을 두고 주황 화살표를 연결한다 → 집합의 범위와 전달 관계를 드러낸다 → 포함되는 모든 항목과 제외되는 항목을 구분할 수 있으면 완료다. 개별 입력이라면 실제 연결 관계대로만 선을 추가한다.
3. 항목 간 대응이 방법의 핵심이라면 확인된 동일 항목에 같은 작은 표식·위치 규칙을 유지하고, 실제로 제거되거나 바뀌는 항목만 다른 상태로 표시한다 → 선택 및 변환의 전후를 추적할 수 있게 한다 → 적어도 대표 항목 하나를 입력에서 출력까지 대응시킬 수 있고, 실제로 없는 일대일 관계를 암시하지 않으면 완료다.

화살표만 두껍게 바꾸면 해결되지 않는다. 상대적 굵기에서는 짙은 주 경로, 파란 하향 선, 주황 입력선이 주변의 얇은 상자 경계보다 이미 잘 보인다. 화살촉 크기도 현재 수신 위치를 읽는 데 충분하다. 문제는 연결 지점, 특히 파란 선과 주황 선의 출발 대상이다. 경로상 파란 선은 상하 구분선을 가로질러 두 부분의 관계를 암시하지만, 시작점을 먼저 확정해야 한다. 역할별 색은 구분되나 파란 선과 주황 선이 어떤 종류의 입력인지 의미를 검증할 수는 없다. 굵기를 늘리면 잘못 정의된 출발점이 더 강하게 보일 뿐이다.

**Pair 04 — 출처 추정 B, 시각적 완성도 B**

B의 위쪽 인코더 출력은 가로축 항목으로, 아래쪽 인코더 출력은 세로축 항목으로 이어진다. 이 두 축이 표의 셀을 구성하고 대각선이 반복 강조되어, 두 집합의 조합 관계가 연결과 배치로 드러난다. 사진의 유무는 이 평가에 영향을 주지 않았다. A도 두 색의 처리 분기와 대각선 강조 행렬을 간결하게 보여 주지만, 왼쪽 두 출력이 오른쪽 행렬의 어느 축과 대응하는지 시각적 연결이 부족하다.

생성본으로 추정한 A의 약점은 다음 세 가지다.

1. 왼쪽 두 분기의 막대 출력과 오른쪽 행렬 사이 → 세로 구분선을 사이에 두고 연결이나 대응 표시가 보이지 않음 → 두 표현을 어떻게 조합해 행렬을 구성하는지 도형만으로 추적하기 어렵다.
2. 왼쪽 위·아래 처리 상자와 각 상자 오른쪽의 막대 묶음 사이 → 입력에서 상자로 들어가는 화살표는 있지만 상자에서 막대 묶음으로 이어지는 선은 없음 → 막대가 처리 결과인지, 상자의 특성 설명인지 인접 배치에 의존해 해석해야 한다.
3. 행렬의 행·열과 대각선 강조 → 왼쪽 두 분기의 파랑·주황 구분이 행·열의 기하학적 구조에 이어지지 않고, 대각선은 별도로 연한 파랑으로 강조됨 → 두 분기와 두 축의 대응, 대각선의 특별한 의미를 한 번에 읽기 어렵다. 가려진 축 라벨이 이를 설명하고 있을 가능성은 남아 있다.

개선 우선순위는 다음과 같다.

1. 실제 행·열 정의를 확인하고 파랑 출력과 주황 출력을 각각 해당 축의 가장자리 또는 항목 묶음에 연결한다 → 행렬이 두 집합의 관계를 나타낸다는 점을 설명한다 → 독자가 어느 출력이 행이고 어느 출력이 열인지 연결만으로 구별할 수 있으면 완료다.
2. 막대 묶음이 처리 상자의 결과가 맞다면 상자 출력 포트와 막대 묶음 사이에 짧은 연결을 추가하고 두 분기에 같은 배치 규칙을 적용한다 → 입력–처리–출력 관계를 완결한다 → 각 막대 묶음의 생성 경로를 분명하게 추적할 수 있으면 완료다.
3. 대각선이 실제로 대응 쌍이나 특별한 관계를 뜻하는지 확인하고, 맞다면 행·열의 같은 항목을 일관된 표식으로 대응시킨다. 아니라면 실제 의미에 맞는 강조 규칙을 사용한다 → 대각선의 강조를 해석 가능한 관계 표시로 만든다 → 강조된 셀이 왜 특별한지 확인된 방법 설명과 일치하고, 존재하지 않는 수치나 성능을 암시하지 않으면 완료다.

화살표만 두껍게 바꾸면 해결되지 않는다. 상대적 굵기에서는 기존 입력 화살표가 처리 상자 테두리보다 뚜렷하다. 화살촉 크기도 상자를 향한 방향을 읽기에 충분하다. 연결 지점에서 기존 화살표의 도착 위치는 분명하지만, 처리 상자 이후와 행렬 축까지의 연결은 빠져 있다. 경로는 현재 짧고 단순해 교차 문제가 없으며, 개선 시에도 두 축으로 향하는 선을 분리할 수 있다. 역할별 파랑·주황 분기는 막대와 상자에서 유지되지만 행렬 축으로 이어지지 않는다. 필요한 것은 굵기 증가보다 연결 추가와 색·축의 일관된 대응이다.

**공통 개선점**

우선 화살표의 시작점과 끝점을 데이터·연산·집합 중 하나에 정확히 붙여야 한다. 이어서 집합의 범위, 합류 방식, 개요와 상세의 대응을 명시하면 좋다. 색과 선 모양은 단순히 서로 다르게 만드는 데 그치지 않고 같은 역할에 반복 적용해야 한다. 작은 막대나 카드 아이콘은 실제 상태 차이 또는 항목 대응을 설명할 때 효과가 있으므로, 설명 목적을 확인한 뒤 필요한 시각 변화만 넣는 것이 좋다. 도형·연산·실험 결과를 늘리는 것 자체가 개선은 아니다.

**이 비교의 한계**

- 이 평가는 지정된 비교 PNG와 평가 지침만 사용했다. 다른 파일, 메타데이터, 원본, 인터넷을 탐색하거나 정답을 확인하지 않았다.
