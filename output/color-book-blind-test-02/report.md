# 최신 color book 적용 figure: 생성 및 블라인드 평가

2026-09-30. 이전 독립 테스트와 동일한 미세유체 액적 선별 요구사항을 사용해, 최신 16개 color book이 포함된 스킬로 새 figure를 생성했습니다. 생성 세션은 이전 대화·생성본·피드백을 제공받지 않았고 `olive-copper`를 선택했습니다. 올리브는 액적, 구리색은 오일 채널, 파랑은 검출·제어 관계에 배정했습니다. 부모 세션은 완성된 그림을 수정하지 않았습니다.

## 블라인드 판정

| 항목 | 결과 |
|---|---|
| 실제 논문으로 추정 | B — 정답 |
| 주관적 확신도 | 60% |
| 시각적 품질 선택 | A, 생성본 — 국소 흐름과 분류의 가독성 기준 |
| 구도 기억 | 특정 논문이나 구도를 기억하지 못했다고 응답 |
| 확실한 구조 오류 | 발견하지 못함 |
| 주요 지적 | 분기점에서 파란 강조 경계·막대·화살촉과 채널 외곽이 밀집하거나 겹침 |

출처 추정의 근거는 B의 부분별 윤곽·음영 처리에 대한 약한 양식상의 인상이었습니다. 평가자는 A 같은 평면 도식도 충분히 출판 가능하다고 명시했습니다. 화살표를 더 굵게 만드는 것보다 강조 경계의 중첩과 끝점의 역할을 정리할 것을 권했습니다.

평가자에게는 원본과 생성본의 **검출·선별 국소 영역**만 양옆에 배치한 [평면 이미지](blind/pair-01.png)와 [중립 프롬프트](blind/evaluator-prompt.md)를 전달했습니다. 모든 내부 라벨·부등식을 가렸고 A/B 위치를 무작위로 정했습니다. 논문 이름·정답·전체 그림·이전 평가를 전달하지 않았습니다. [원문 응답](feedback-blind.md)을 수정 없이 저장하고 해시를 기록한 다음에만 정답과 전체 생성본을 공개했습니다.

## 라벨 공개 후 피드백

최초 응답을 저장한 뒤, 같은 검증 세션에 정답과 전체 생성본 및 원래 요구사항을 제공했습니다. 이 단계는 블라인드 평가가 아닙니다. [후속 응답 원문](feedback-labeled.md)과 [후속 검토 프롬프트](blind/prompt-labeled.md)를 별도로 보존했습니다. 최초 응답의 해시는 공개 후에도 동일합니다.

검증자는 라벨을 보자 검출 위치→검출기→제어기→전극의 관계와 양쪽 출구의 조건이 명확해졌다고 판단했습니다. 필수 단계 누락이나 명백한 구조 오류는 발견하지 못했습니다. 최종적으로 남긴 개선점은 두 가지입니다.

| 우선순위 | 개선 사항 | 편집 방향과 완료 기준 |
|---|---|---|
| 1 · 조건부 설명 개선 | 연한 녹색 액적은 범례에 정의되지 않은 세 번째 표시 | 판정 전 상태를 의도했다면 그 의미를 명시하고 사용을 일관되게 합니다. 단순 장식이라면 차이를 제거합니다. 독자가 중간 신호값이나 제3의 임계값 범주를 추정하지 않게 하는 것이 완료 기준입니다. |
| 2 · 마무리 조정 | 분기점의 파란 강조 사각형과 갈색 채널 꼭짓점, 전극 아래 화살촉의 중첩 | 강조 경계와 화살촉의 간격을 국소적으로 조정합니다. 제어기→전극의 실제 연결과 전극의 의미는 보존하며, 최종 크기에서 각 경계를 따로 추적할 수 있어야 합니다. |

화살표 굵기는 현재도 충분하다고 평가했습니다. 연속 채널, 배양 뒤 검출, 물질과 제어의 구분, 채운 원/빈 원 및 출구 부등식은 유지할 요소로 꼽았습니다. 이번 산출물은 **평가받은 그대로** 보존했으며 피드백을 반영해 사후 수정하지 않았습니다.

## 원본과 범위

B는 De Jonghe et al.의 [spinDrop Figure 1C](https://www.nature.com/articles/s41467-023-40322-w/figures/1)에서 사진을 제외한 장치 도식입니다. 생성본과 원본 모두 내부 라벨을 가리고 검출·선별 영역을 잘랐습니다. 사진 유무를 출처 단서로 사용하지 않도록 사진은 포함하지 않았습니다. 배율은 같은 표시 폭과 원래 종횡비를 기준으로 정했습니다. [원본 표기 및 변경 사항](SOURCES.md).

단, 논문은 구체적인 실험 장치이고 생성 과제는 치수·생물학적 내용·전극 상세가 정의되지 않은 가상의 방법 개요입니다. 표현 범위, 장치 구조, 요소 크기와 가림 밀도가 다릅니다. 따라서 더 복잡한 장치처럼 보인다는 이유로 생성본에 내용을 추가해서는 안 됩니다.

## 검증 범위

- 저장된 PPTX의 필수 내용 검사를 통과했습니다. 78개 native shape, 4개 native connector, 1개 group을 확인했습니다. 연결 검사에서 렌더링 재검토 대상으로 지정된 연결은 없었습니다.
- 생성 세션은 저장된 PPTX를 번들 LibreOffice로 렌더링하고 177.8 mm에 해당하는 보기와 축소 흑백 보기를 검토했습니다. 부모 세션도 전달 파일과 생성 파일의 해시 일치 및 내용 검사를 확인했습니다.
- 생성과 평가 모두 이전 대화를 전달하지 않은 별도 컨텍스트를 사용했습니다. 별도 컨텍스트가 다른 모델이나 서비스라는 의미는 아닙니다. 평가자가 확인할 수 있는 정체성은 GPT-6 기반 Codex이며 정확한 변형·샘플링 설정은 제공되지 않았습니다.
- 이 결과는 **한 쌍, 한 평가자**의 정성적 관찰입니다. 과거 테스트와 과제·참고 그림·평가 조건이 같지 않으므로 과거 정답 확신도와 직접 비교하지 않습니다. 색상만 바꾼 통제 실험도 아니므로 color book의 인과적 효과나 출판 수준 도달을 입증하지 않습니다.
- PowerPoint 실앱 편집 테스트는 수행하지 않았습니다. 라벨을 공개한 후속 검토는 최초 블라인드 판정과 별도로 기록합니다.
